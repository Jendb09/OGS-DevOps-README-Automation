## Automation

This project demonstrates:

- Automatic README activity updates using GitHub Actions
- Secure authentication using GitHub Actions Secrets
- Least-privilege repository permissions
- Jira and GitHub development linkage
- Automatic Jira issue transition after pull request merge
- README marker validation CI

## Security

Authentication credentials are stored securely using GitHub Actions Secrets. Sensitive token values are never committed to the repository.
